Duck Obstacle Course

One duck, one course, reactive depth control, no global map — the duck_course Python package running in your browser.

Source on GitHub
What you are watching. A 2-D kinematic proxy drives the real ReactivePolicy, sectors() and Episode code with synthetic ray-cast depth. There are no legs, balance, falls, slip or trained locomotion policies here. This shows the navigation logic; it is not evidence of MicroDuck locomotion. The closed-loop MuJoCo workflow is described in the repository README.
